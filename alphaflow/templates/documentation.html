AlphaFlow Developer Handbook

Overview

AlphaFlow is an isolated Flask application designed to scan historical OPRA data to identify anomalous institutional options flow (Smart Money Sweeps). It is built with complete separation from the legacy options_whale codebase, running on port 5001 to prevent conflicts.

System Architecture

  • Frontend (templates/index.html): A visual node-based programming canvas built in Vanilla JS using Drawflow.
  • Backend Server (server.py): A lightweight Flask server exposing the REST API.
  • Execution Engine (engine.py): The core processing script that runs the historical logic, interacting with SQLite and Databento APIs.
  • Database (alphaflow.db): Local SQLite storage tracking detected swing setups.

1. The Execution Engine (engine.py)

The engine executes a simulated historical Databento scan to capture swing setups from the previous trading day.

Universe Pre-Filter

Running a heavy OPRA historical query against 8,000 tickers incurs immense data costs. Therefore, the engine first simulates gathering a target universe of small/mid-cap equities ($100M - $10B) via yfinance. See get_yfinance_universe().

The Databento Query

In a live scenario, the engine utilizes the Databento Historical API using the OPRA mbp-1 schema:

client = db.Historical(key=os.getenv('DATABENTO_API_KEY'))
client.timeseries.get_range(
    dataset='OPRA.PILLAR', 
    schema='mbp-1', 
    symbols=target_symbols, 
    start='2026-05-18T00:00'
)
Algorithmic Expiration Recommendation: During processing, the engine calculates a recommended contract expiration date (padding the required swing term with sufficient theta runway) and inserts it directly into the expiration column of the SQLite database.

2. Modifying the Visual Canvas (index.html)

The UI is completely free of React and Webpack. It uses standard DOM manipulation alongside the Drawflow library.

To add a new visual Node, define the raw HTML string inside a backtick template literal, and register it with the editor:

const customNodeHTML = `
<div>
    <div class="title-box"><span>New Filter</span></div>
    <div class="box">
        <label>Parameter</label>
        <input type="text" id="custom_param">
    </div>
</div>`;
editor.addNode('custom', 1, 1, 100, 200, 'custom', {}, customNodeHTML);

3. Database Schema (SQLite)

The swing_plays table is designed dynamically. If you add new parameters to the engine, you must modify the init_db() function to drop and recreate the table, or run an ALTER TABLE script.

  • id: Auto-increment primary key.
  • date: The date of the execution.
  • ticker: Target equity symbol.
  • contract: Detected anomalous option leg.
  • expiration: Algorithmic recommended exit date.
  • max_risk: Computed maximum dollar risk per trade.
